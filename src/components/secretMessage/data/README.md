# Secret-message quote catalog

The initial batch contains the three previously sourced excerpts plus 197 short quotations selected from https://github.com/dwyl/quotes (retrieved 2026-10-24). Each imported entry links to its location in that collection. The source collection's GPL-2.0 license is retained in LICENSE.quotes. The imported JSON data retains that license.

Selection: 5–16 words, short enough for elementary readers, focused on learning, kindness, nature, character, and persistence. Entries were reviewed for classroom suitability and normalized for duplicate text. Imported author credits are **attributions reported by the collection**, not independently authenticated primary-source quotations; the completion screen says “Attributed to”. The original three entries retain their direct source links.

After the first batch, messages are composed locally from reviewed educational sentence fragments and explicitly credited to **Math Whiz original**. They are not represented as historical quotations. Generation is deterministic by batch, never cycles, and needs no external AI service. The combinatorial pool has a defined capacity; if it is ever exhausted, it stops instead of repeating messages.

Catalog order and IDs are persistent. Do not reorder the initial batch, modify an existing ID's text, or change generator version/fragments without a progress migration: students' completed batches refer to these exact contents.
